Understand the retained negative finding and the limits of the study’s scientific and presentation checks.

What the checks establish

The 2023 validation applied the selected settings unchanged. Humidity's statistical stream flagged 107 of 8,760 assumed-normal ready hours (1.2215%); June was 31 of 720 (4.3056%). These exceeded the declared annual and monthly limits. The negative finding is retained in the final interpretation.

Read the 2023 validation workflow for the full annual and monthly account. The bounded code checks below and the website's navigation, filtering, copy and download checks have a narrower purpose: they check specified behaviour. They do not reproduce the scientific experiments, establish participant usability or demonstrate production reliability.

Using the Python files

Read complete files on each study and results page. Choose a file, then use Copy code or Download .py. Copy preserves indentation; wrapping only changes the display. The site does not execute Python.

Download all 66 Python files and supporting files (.zip). Extract the complete folder to keep imports and configuration together. The download contains the public source shown on the website, requirement lists and report templates.

The public copy omits administrative metadata from one Python file, one protocol file and one report template. The numerical methods and scoring logic are unchanged. Exact historical execution identities belong to the original execution archive.

Environment requirements

The scientific environment used Python 3.12.14 and NumPy 2.3.5. Its scientific requirements are separate from the reporting requirements, which use NumPy 2.5.3 and Matplotlib 3.10.7. Use separate environments for these requirement lists. No installation is needed to browse the findings.

Run the nine bounded checks

After extracting the complete code download, open a terminal in that folder and run the command below with Python 3.12. The checks use only the standard library and small fabricated inputs; they do not fetch weather data or launch the experiment.

python -B -X utf8 checks/check_core.py

Expected result: 9 tests, OK. These checks cover prediction identity, common cohorts, null ratios, compatible detection credit, horizon limits, miss partitions, exposure, truth isolation and fixed sensitivity inputs.

Full-study prerequisites

A full replay additionally needs the immutable source responses, prepared series, 2021 fits, 2022 development evidence, 2023 validation, final input and label preparation, original frozen source and settings, and complete execution outputs. Those inputs are not included in the code download. Historical paths and input assumptions mean the full experiment is not ready to run from the public files alone.

The scientific freeze summary provides the environment, retained labels and identities of the design and settings. It is a summary, not the full execution freeze.

Reading the saved analysis

The explorer filters completed results; it does not refit a model or rerun a detector. Comparisons retain the declared common cohorts, missed detections, undefined ratios and separate fault families. There is no overall detector ranking. Humidity remains exploratory and the background is assumed normal, not certified healthy.

All twelve complete tables preserve every published row. Export readback evidence records the checks on exported values. Timeline selection rules describe how examples were chosen, and the figure environment records the reporting versions. These support interpretation of the saved results; they do not establish operational reliability or independent human review.
