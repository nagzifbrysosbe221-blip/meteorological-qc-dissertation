Period 1 of 4 / Model fitting

2021 — Fitting

Read, copy or download the complete Python code ↓

The 2021 observations were used to estimate expected temperature and humidity at De Bilt. This stage produced the prediction models and the error summaries needed to interpret later differences between observed and expected readings.

Recorded outcome. All four candidates fitted successfully: two for temperature and two for humidity. Each used 8,760 hourly records, with no fitting rows excluded. Their fitted coefficients, residual centres and residual scales were saved. Model suitability was assessed in the next period.

Review the fitting resultsOpen the evidence summary

“2021” identifies the source observations. The fitting records were produced in October 2026. This page summarises those saved records; it does not run or refit a model.

1 / Purpose and inputs

What the fitting stage needed to establish

A warm afternoon or a cold winter day is not automatically a fault. The study therefore needed a model of expected behaviour before it could monitor persistent departures. Fitting estimated the numerical weights in that prediction formula from the 2021 observations.

The output was an expected value for the current observation. The reference-assisted model used Schiphol’s observation from the same hour, so its purpose was comparison with current weather conditions rather than forecasting future weather.

InputHow it was used
De Bilt, station 260Temperature and relative humidity were fitted separately as the quantities to predict.
Schiphol, station 240The same variable at the same hour supplied an additional input to the reference-assisted candidate.
2021 source dates1 January–31 December, with 8,760 expected hourly records per variable. Original source-date membership was retained through the hour-24 timestamp conversion.
Calendar informationTime of year and time of day represented recurring seasonal and daily patterns.
Eligible recordsEach fit required a unique, finite target value. The reference-assisted fit also required a unique, finite same-hour reference value. All 8,760 hours were usable for each of the four candidates.

The background readings were assumed normal. The study did not certify them as fault-free, fill missing readings, clip unusual values or remove observations because a fitted model disagreed with them.

2 / Candidate models

Statistical modelling: estimating an expected reading

Why a prediction model is needed. Weather changes by season and time of day. A raw change is not automatically drift. The fitted model estimates the expected reading; the difference between the observed and predicted value is the residual. H monitors those residuals for sustained departures, alongside the same integrity rules used by R.

CandidateInformation usedPurpose in the comparison
S — Seasonal model13 calendar terms describing an overall level, annual patterns, daily patterns and how daily patterns vary with season.Estimate De Bilt’s recurring behaviour from the calendar alone. This also provides a comparator for the model using a reference station.
P — Reference-assisted modelThe same 13 types of calendar term plus Schiphol’s same-hour reading: 14 fitted coefficients in total.Use information about the weather occurring at the reference station as well as the calendar. Its calendar and reference coefficients were fitted together.

Temperature S, temperature P, humidity S and humidity P were four separate fits. In P, the system learned the relationship between the stations; it did not assume that De Bilt should equal Schiphol. The availability of a reference observation did not establish that it was accurate or representative.

Technical detail: what were the 13 calendar terms?

There was one intercept, four annual sine/cosine terms, four daily sine/cosine terms, and four products combining the first annual and daily terms: 1 + 4 + 4 + 4 = 13. P added one same-variable reference predictor.

The annual terms used elapsed UTC time as a fraction of the current calendar year; daily terms used fractional UTC hour. The two harmonics for each cycle and their interactions were specified in advance. Previous target readings were not used as predictors.

Sources: dissertation Appendix A2; implemented feature definitions and fitting. Exact feature names and coefficients are retained in the fitting evidence summary.

3 / Practical workflow

How the observations became fitted models

  1. Restricted the input to the fitting period. The program checked the source-year role before using numerical observations. The 2022, 2023 and 2024 readings were not used to estimate these coefficients.
  2. Prepared one fitting row per eligible hour. Each row contained the calendar inputs and the observed De Bilt value. For P, it also contained the matching Schiphol value. Original record identities were retained for traceability.
  3. Estimated the coefficients. Ordinary least squares chose the weights that minimised the total squared differences between the observed and predicted values across the fitting rows. A stable numerical method checked that the required coefficients could be estimated.
  4. Calculated the residuals. For every usable fitting hour, the residual was the observed De Bilt value minus the model’s prediction. A positive residual meant the reading was above the prediction; a negative residual meant it was below.
  5. Saved the residual centre and scale. The centre was the mean residual. The scale was the sample standard deviation, describing the spread of the fitting errors. Later monitoring used these saved values to express new residuals relative to the 2021 error spread.
  6. Recorded diagnostic summaries and preserved the outputs. The saved evidence included fitting counts, exclusions, coefficient values, numerical checks, hourly and monthly error summaries, extremes and residual dependence. These diagnostics did not remove fitting rows.
Optional illustration: turning a prediction error into a comparable value

Invented observations for explanation only. Suppose a temperature reading is 15 °C and the prediction is 13 °C. The residual is +2 °C. Using the actual saved temperature P scale of approximately 1.0899 °C and its near-zero centre gives a standardised residual of about +1.835.

This means the reading is roughly 1.835 fitting-error standard deviations above the prediction. It is not a probability of a fault or an alarm by itself; the later monitoring stage accumulates residual information and applies its separately selected threshold.

Calculation: (residual − saved centre) ÷ saved scale.

Sources: fit, predict and standardised-residual implementation; frozen fitting procedure. Dissertation: Section 3.4 and Appendix A2.

For both variables, the reference-assisted model had a narrower residual spread on the fitting data. This is an observed fitting result. P also had an additional predictor, so this result alone did not establish better performance in another year or satisfy the later model-selection rules.

All four mean residuals were approximately zero. With an intercept in the least-squares fit, a near-zero overall mean is expected; it does not mean every prediction was accurate or that errors disappeared in each month.

Numerical checks and precision

The S fits had full rank 13 of 13 and the P fits 14 of 14. Full rank means that the fitted inputs supplied the independent information needed to estimate the stated coefficients. It is a numerical check, not certification of the model’s scientific suitability.

All saved coefficients, centres and scales were finite, and every scale was positive. The sample standard deviation used denominator 8,759 (n − 1), as specified in Appendix A2. Displayed scales are rounded to four decimal places; the exact values remain in the evidence summary.

Fitting success and eligibility are different decisions. Humidity fitted successfully in 2021. Its later 2022 suitability checks failed. The original combined fitting-and-gates run therefore has the status revision_required; this does not mean that the four fitting calculations failed.

Source: four saved fits, numerical diagnostics and original combined-run status. The overview explains the later selection outcome.

5 / Descriptive diagnostics

Exploratory analysis: what the fitting diagnostics showed

Purpose. Examine the shape and timing of model errors before interpreting later alarms. The recorded diagnostics describe residual ranges, summaries by UTC hour and source month, and correlations between errors separated by 1, 6, 24, 48 and 168 hours. They help reveal remaining patterns rather than certify that the background is healthy or independent.

Reading the evidence. The early coverage and range summaries describe the observations; the diagnostics below describe how the fitted models represented them. No detector-led outlier removal was applied. The complete implementation is in scientific_models.py, including its diagnostics function.

The humidity prediction was not constrained to 0–100%. Humidity P’s saved 2021 prediction range reached 101.3697%. This was a model prediction, not an observed humidity reading. Predictions were retained without clipping, allowing this limitation to remain visible.

These checks described behaviour. The diagnostics recorded no cleaning and no unavailable hours for the four fitted series. They did not identify the physical cause of an error, certify the reference station, or justify deleting inconvenient observations.

"""Submitted A2: frozen calendar OLS and conditional same-variable reference OLS."""
from collections import Counter
from dataclasses import dataclass
from datetime import datetime, timedelta, timezone
import math
import numpy as np

from early_scientific import require_role

FEATURES = ('intercept', 'annual_sin1', 'annual_cos1', 'annual_sin2', 'annual_cos2',
            'daily_sin1', 'daily_cos1', 'daily_sin2', 'daily_cos2',
            'annual_sin1_daily_sin1', 'annual_sin1_daily_cos1',
            'annual_cos1_daily_sin1', 'annual_cos1_daily_cos1')


def calendar_features(stamp):
    if stamp.tzinfo is None:
        raise ValueError('UTC-aware timestamp required')
    t = stamp.astimezone(timezone.utc)
    start = datetime(t.year, 1, 1, tzinfo=timezone.utc)
    end = datetime(t.year + 1, 1, 1, tzinfo=timezone.utc)
    annual = 2 * math.pi * (t - start).total_seconds() / (end - start).total_seconds()
    daily = 2 * math.pi * (t.hour + t.minute / 60 + (t.second + t.microsecond / 1e6) / 3600) / 24
    a, b, c, d = math.sin(annual), math.cos(annual), math.sin(daily), math.cos(daily)
    return (1., a, b, math.sin(2*annual), math.cos(2*annual), c, d,
            math.sin(2*daily), math.cos(2*daily), a*c, a*d, b*c, b*d)


def design(hour, kind):
    if kind not in ('S', 'P'):
        raise ValueError('Only submitted S/P candidates are supported')
    x = calendar_features(hour.utc)
    if kind == 'P':
        if hour.reference.reason != 'finite' or hour.reference.value is None:
            return None, 'reference_' + hour.reference.reason
        if not math.isfinite(hour.reference.value):
            return None, 'reference_nonfinite'
        x += (hour.reference.value,)
    return x, None


def stable_ols(x, y):
    """Scale columns then solve by SVD; never form X'X or accept deficient rank."""
    x, y = np.asarray(x, dtype=np.float64), np.asarray(y, dtype=np.float64)
    if x.ndim != 2 or y.shape != (len(x),) or len(x) < 2:
        raise ValueError('Invalid/insufficient fit dimensions')
    if not np.isfinite(x).all() or not np.isfinite(y).all():
        raise ValueError('Nonfinite fit input')
    norms = np.linalg.norm(x, axis=0)
    if not np.isfinite(norms).all() or np.any(norms == 0):
        raise ValueError('Rank deficient or nonfinite column norm')
    rcond = np.finfo(np.float64).eps * max(x.shape)
    scaled_beta, _, rank, singular = np.linalg.lstsq(x / norms, y, rcond=rcond)
    if rank != x.shape[1]:
        raise ValueError(f'Full column rank required: {rank}/{x.shape[1]}')
    beta = scaled_beta / norms
    residual = y - x @ beta
    centre = float(np.mean(residual))
    scale = float(np.std(residual, ddof=1))  # A2 says n-1, NOT n-p.
    if not np.isfinite(beta).all() or not math.isfinite(centre) or not math.isfinite(scale):
        raise ValueError('Nonfinite fit output')
    return tuple(float(b) for b in beta), centre, scale, {
        'rank': int(rank), 'columns': x.shape[1], 'rcond': float(rcond),
        'singular_values_scaled': singular.tolist(), 'column_norms': norms.tolist(),
        'scaled_condition_number': float(singular[0] / singular[-1]),
        'residual_scale_denominator': len(x)-1, 'solver': 'numpy.linalg.lstsq column-scaled SVD'}


@dataclass(frozen=True)
class Model:
    kind: str
    variable: str
    coefficients: tuple[float, ...]
    centre: float | None
    scale: float | None
    status: str
    reason: str | None


def fit(series, kind):
    require_role(series, 'fit')  # Before looking at numeric inputs.
    if kind not in ('S', 'P'):
        raise ValueError('Unknown model')
    x, y, ids, excluded = [], [], [], Counter()
    for hour in series.hours:
        if hour.target.reason != 'finite' or hour.target.value is None:
            excluded['target_' + hour.target.reason] += 1
            continue
        if not math.isfinite(hour.target.value):
            excluded['target_nonfinite'] += 1
            continue
        row, reason = design(hour, kind)
        if reason:
            excluded[reason] += 1
            continue
        x.append(row); y.append(hour.target.value)
        ids.append({'source_date': hour.source_day.isoformat(), 'source_hour': hour.source_hour,
                    'target': hour.target.record_ids,
                    'reference': hour.reference.record_ids if kind == 'P' else ()})
    record = {'kind': kind, 'variable': series.variable, 'source_year': 2021,
              'acceptance_sha256': series.acceptance_sha256, 'raw_sha256': series.raw_sha256,
              'features': FEATURES + (('schiphol_same_variable',) if kind == 'P' else ()),
              'fit_rows': ids, 'n': len(y), 'exclusions': dict(excluded)}
    try:
        beta, centre, scale, diagnostics = stable_ols(x, y)
    except (ValueError, np.linalg.LinAlgError, FloatingPointError) as exc:
        return Model(kind, series.variable, (), None, None, 'fit_failed', str(exc)), record
    record['diagnostics'] = diagnostics
    status = 'fitted' if scale > 0 else 'ineligible_scale'
    return Model(kind, series.variable, beta, centre, scale, status,
                 None if scale > 0 else 'Residual sample standard deviation must be positive'), record


def predict(model, hour):
    if not model.coefficients:
        return None, 'model_fit_failed'
    x, reason = design(hour, model.kind)
    if reason:
        return None, reason
    value = math.fsum(a*b for a, b in zip(x, model.coefficients, strict=True))
    return (value, None) if math.isfinite(value) else (None, 'nonfinite_prediction')


def standardised_residual(model, hour):
    if model.status != 'fitted' or model.scale is None or model.scale <= 0:
        return None, 'model_ineligible'
    if hour.target.reason != 'finite' or hour.target.value is None:
        return None, 'target_' + hour.target.reason
    value, reason = predict(model, hour)
    if reason:
        return None, reason
    u = (hour.target.value - value - model.centre) / model.scale
    return (u, None) if math.isfinite(u) else (None, 'nonfinite_residual')


def _summary(errors, expected, scale):
    n = len(errors)
    mean = math.fsum(errors) / n if n else None
    return {'usable': n, 'expected': expected, 'coverage': n/expected if expected else None,
            'mean_error': mean, 'rmse': math.sqrt(math.fsum(e*e for e in errors)/n) if n else None,
            'absolute_mean_over_frozen_scale': abs(mean)/scale if n and scale and scale > 0 else None}


def assess_gates(series, s, p):
    """2022 only; full independent schedule denominators, source-month grouping."""
    require_role(series, 'development')
    if s.kind != 'S' or p.kind != 'P' or s.variable != series.variable or p.variable != series.variable:
        raise ValueError('Wrong candidate or variable')
    expected = Counter(h.source_day.month for h in series.hours)
    # Partial fixtures are not mistaken for a scientifically complete 2022 gate year.
    import calendar
    if expected != Counter({m: calendar.monthrange(2022, m)[1]*24 for m in range(1,13)}):
        raise ValueError('A2 gates require all expected 2022 source hours')
    errors = {'S': {}, 'P': {}}
    for i, h in enumerate(series.hours):
        if h.target.reason != 'finite' or h.target.value is None or not math.isfinite(h.target.value):
            continue
        for model in (s, p):
            value, reason = predict(model, h)
            if reason is None:
                errors[model.kind][i] = h.target.value - value
    candidates = {}
    for model in (s, p):
        e = errors[model.kind]
        annual = _summary(list(e.values()), len(series.hours), model.scale)
        monthly = {str(m): _summary([v for i,v in e.items() if series.hours[i].source_day.month == m],
                                     expected[m], model.scale) for m in range(1,13)}
        passed = (model.status == 'fitted' and annual['coverage'] >= .95 and
                  all(v['coverage'] >= .90 and v['absolute_mean_over_frozen_scale'] is not None and
                      v['absolute_mean_over_frozen_scale'] <= .5 for v in monthly.values()))
        candidates[model.kind] = {'annual': annual, 'monthly': monthly, 'own_gates_pass': passed,
                                  'fit_status': model.status}
    common = sorted(errors['S'].keys() & errors['P'].keys())
    def comparison(indices):
        a = _summary([errors['S'][i] for i in indices], len(indices), None)['rmse']
        b = _summary([errors['P'][i] for i in indices], len(indices), None)['rmse']
        return {'n': len(indices), 'S_rmse': a, 'P_rmse': b,
                'ratio': b/a if a is not None and a > 0 else None}
    annual = comparison(common)
    monthly = {str(m): comparison([i for i in common if series.hours[i].source_day.month == m])
               for m in range(1,13)}
    improvement = (annual['ratio'] is not None and annual['ratio'] <= .90 and
                   all(v['ratio'] is not None and v['ratio'] <= 1.10 for v in monthly.values()))
    # P cannot rescue failure to fit the full-rank S comparator.
    if not s.coefficients:
        selected, reason = None, 'full_rank_S_comparator_failed_revision_required'
    elif candidates['P']['own_gates_pass'] and improvement:
        selected, reason = 'P', 'all_P_gates_pass'
    elif candidates['S']['own_gates_pass']:
        selected, reason = 'S', 'P_ineligible_or_improvement_unestablished'
    else:
        selected, reason = None, 'no_eligible_candidate_revision_required'
    return {'year': 2022, 'variable': series.variable, 'candidates': candidates,
            'common_sample': {'annual': annual, 'monthly': monthly},
            'P_comparative_gates_pass': improvement, 'selected': selected, 'reason': reason,
            'calibration_complete': False, 'scientific_freeze': False}


def diagnostics(series, model):
    """Descriptive A2 checks only: no diagnostic can remove a fitting row."""
    residuals, target, predicted = {}, [], []
    hourly = {str(h): [] for h in range(24)}
    monthly = {str(m): [] for m in range(1,13)}
    expected_hourly = Counter(str(h.utc.hour) for h in series.hours)
    expected_monthly = Counter(str(h.source_day.month) for h in series.hours)
    unavailable = Counter()
    for hour in series.hours:
        if hour.target.reason != 'finite' or hour.target.value is None:
            unavailable['target_' + hour.target.reason] += 1
            continue
        value, reason = predict(model, hour)
        if reason:
            unavailable[reason] += 1
            continue
        error = hour.target.value-value
        residuals[hour.utc] = error
        hourly[str(hour.utc.hour)].append(error)
        monthly[str(hour.source_day.month)].append(error)
        target.append(hour.target.value); predicted.append(value)
    def extrema(values):
        return {'min': min(values) if values else None, 'max': max(values) if values else None}
    dependence = {}
    for lag in (1,6,24,48,168):
        pairs = [(residuals[t-timedelta(hours=lag)],v) for t,v in residuals.items()
                 if t-timedelta(hours=lag) in residuals]
        corr, reason = None, 'insufficient_pairs'
        if len(pairs) >= 2:
            a,b = np.asarray(pairs,dtype=float).T
            a,b = a-a.mean(), b-b.mean()
            denominator = float(np.linalg.norm(a)*np.linalg.norm(b))
            reason = 'zero_variance' if denominator == 0 else None
            if denominator > 0: corr = float(np.dot(a,b)/denominator)
        dependence[str(lag)] = {'pairs':len(pairs),'correlation':corr,'reason':reason}
    return {'source_year':series.source_year,'variable':series.variable,'model':model.kind,
            'unavailable':dict(unavailable),'target_extrema':extrema(target),
            'prediction_extrema':extrema(predicted),'residual_extrema':extrema(list(residuals.values())),
            'hourly_UTC':{k:_summary(v,expected_hourly[k],model.scale) for k,v in hourly.items()},
            'monthly_source_date':{k:_summary(v,expected_monthly[k],model.scale) for k,v in monthly.items()},
            'actual_hour_lag_dependence':dependence,'cleaning_applied':False,
            'limits':'Descriptive dependence/representativeness diagnostics; no health or independence certification'}
